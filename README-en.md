# EMI for Casualties: Unknown

> A crafting-path planner and item catalog for *Casualties: Unknown*

Chinese: [README.md](README.md)

## Overview

This mod adds a crafting-tree assistant similar to the Minecraft [EMI](https://modrinth.com/mod/emi) mod to the base game.

![](https://pic.imgdd.cc/i/033xFoyHrWwYo2rleXtHaU.png)

### Installation

Place the `EMI` folder in `BepInEx/plugins/`. The folder contains:

- `EMI.dll`
- `EMI.pdb`
