# EMI for Casualties: Unknown

> 适配游戏《未知伤亡》的合成树、图鉴查看的功能强大的辅助工具

## 简介

该模组为原版游戏添加了与 Minecraft [EMI](https://modrinth.com/mod/emi) 模组相似的合成树辅助工具。

![](https://pic.imgdd.cc/i/033xFoyHrWwYo2rleXtHaU.png)

### 安装方法

把 `EMI` 文件夹放到 `BepInEx/plugins/` 下，内含：

- `EMI.dll`
- `EMI.pdb`
